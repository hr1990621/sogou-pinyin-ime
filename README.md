# 搜影拼音输入法 (Sogou-Style Chinese Pinyin IME)

一款参照搜狗输入法交互与体验开发的中文拼音输入法，采用 **纯 Python 标准库后端 + 原生 Web 前端**（零第三方依赖），内置 **55.2 万+ 现代汉语大词库（雾凇拼音 Rime-ICE）**，主打 **Viterbi 整句输入**、**上下文智能自动补全** 与 **SQLite 本地持久化记忆**。

---

## 核心功能说明

### 1. 55.2 万+ 现代汉语大词库与双层毫秒级检索
- **开源词库融合**：整合雾凇拼音（Rime-ICE）的《通用规范汉字表》8105 字表（`8105.dict.yaml`）、现代汉语基础词库（`base.dict.yaml`）以及精选现代短语与搭配表（`curated_phrases.txt`），编译后共包含 **552,211 条词条**（其中单字 **8,757** 条、多字词 **543,454** 条）及 **107 组常用上下文搭配**。
- **双层混合索引架构**：
  - **SQLite 多列 B-tree 索引**（`data/ime_dict.db`）：按全拼、紧凑拼音、声母简拼、词条建立复合降序索引，支持全量词库精确匹配与亚毫秒级查询。
  - **4.5 万高频热词内存二分索引**：服务启动时自动将最高频的 45,000 个多字词加载为排序数组（启动耗时约 0.4s），通过 `bisect` 二分前缀扫描实现毫秒级拼音前缀补全与中文上下文补全。

### 2. 全拼 / 简拼 / 混拼与 Viterbi 整句切分
- **Beam DP 拼音切分器**（`engine/pinyin_parser.py`）：内置完整现代汉语拼音音节表与合法前缀表，自动生成 Top-K 拼音切分路径，支持：
  - **全拼整句**：`woxiangqubeijinglvyou` → `我想去北京旅游`
  - **简拼输入**：`rgzn` → `人工智能`、`jttq` → `今天天气`
  - **混拼与未完成音节**：`jinttq` → `今天天气`、`zhongg` → `中国`
  - **手动隔音符**：`xi'an` → `西安`
- **Viterbi 动态规划整句解码**：在多音节输入时综合基础词频、多字词内聚奖励、词边界惩罚、用户记忆加权与上下文搭配得分，自动拼出最优整句候选。
- **渐进分步选词**：输入长拼音时同时提供前缀子词候选，支持先选前半部分词、再继续选剩余拼音，并自动拼接完成上屏。

### 3. 智能自动补全与上下文联想
- **拼音前缀自动补全**：尚未敲完完整拼音时（如 `zhongg`、`jintia`、`rgz`、`jttq`），实时从用户记忆与高频热词索引补全完整词语/短语，并在候选词旁显示剩余拼音提示（如 `+uo`、`+zhen'hao`）。
- **行内幽灵补全（Ghost Text）**：在编辑器光标后直接以半透明灰色显示上下文预测文本与 `Tab` 徽标（例如输入 `今天天` 浮现 `气真好 [Tab]`、输入 `自然语言` 浮现 `处理 [Tab]`），按 `Tab` 键即可一键采纳上屏。
- **上屏后连续联想模式**：选词上屏后（如 `人工`、`今天`、`搜狗`），候选框自动切换为「联想」模式，展示高频后续搭配词，支持直接按数字键或空格继续连打。

### 4. SQLite 本地持久化记忆引擎
所有个人输入习惯均实时持久化至本地 SQLite 数据库（`data/user_memory.db`，开启 WAL 模式 + 内存热缓存），重启服务不丢失：
- **动态词频 + 时间衰减提权**：每次选词自动增加个人词频，结合指数衰减权重（半衰期约 14 天，保留 0.35 下限），常用词自动稳定置顶。
- **自动新造词学习**：当用户通过分步选词拼出词库未收录的新短语时（例如输入 `mayiyinli`，先选 `蚂蚁` 再选 `引力`），系统自动将组合短语 `蚂蚁引力` 记为新词；下次输入全拼 `mayiyinli` 或简拼 `myyl` 即可首位直出。
- **上下文二元联想记忆（Bigram）**：自动学习用户常用的前后词搭配（如 `明天 → 写代码`），下次输入前词后优先在幽灵补全和候选中推荐。
- **可视化记忆中心**：Web 右侧面板支持手动添加自定义词条（词条 + 空格拼音）、浏览已学习词汇与联想对、逐条删除、一键导出 JSON 备份以及清空记忆。

### 5. 搜狗风格 Web 交互与算法透视面板
- **光标跟随悬浮候选框**：实时追踪光标位置自动避让边界，支持横向候选列表、分页切换与标签标注（`记忆` / `新词` / `整句` / `补全` / `简拼` / `词库` / `联想`）。
- **完整中文输入体验**：
  - 轻按 `Shift` 切换中/英文模式
  - 中文全角标点映射与中英文智能成对引号（`“”` / `‘’`）
  - 浮动状态栏快速开关「补全」「记忆」「标点」「中英」
  - 内置 3 套主题皮肤：**经典白（Classic）** / **极光蓝（Aurora）** / **暗夜黑（Dark）**
  - 顶部内置 5 个一键快捷体验场景（整句输入、简拼补全、前缀补全、上下文补全、新造词记忆）
- **实时「算法透视」面板**：实时可视化展示拼音切分方案、Top 候选词评分拆解（基础词库分 / 记忆加权分 / 上下文联想分）以及每次上屏触发的学习事件播报。

## 快捷键说明

| 按键 | 功能 |
| --- | --- |
| `a-z` | 输入拼音字母 |
| `'` | 手动分隔音节（如 `xi'an`） |
| `Space` / `1-5` | 选中首选词 / 指定序号候选词上屏 |
| `Tab` | 采纳行内灰色幽灵补全（Ghost Text） |
| `-` / `=` | 候选词上一页 / 下一页 |
| `Shift`（单独轻按） | 切换中文 / 英文输入模式 |
| `Enter` | 将当前输入的原始英文字母直接上屏 |
| `Esc` | 清空当前拼音缓冲 / 关闭联想候选框 |

## 快速开始

### 环境要求
- **Python 3.10+**（完全基于标准库 `http.server`、`sqlite3`、`bisect` 等，**无需安装任何第三方依赖**）
- 现代浏览器（Chrome / Edge / Firefox / Safari）

### 启动服务

```bash
git clone https://github.com/hr1990621/sogou-pinyin-ime.git
cd sogou-pinyin-ime
python server.py
```

> **首次启动说明**：仓库不包含编译后的 `data/ime_dict.db`（约 74 MB），首次运行 `python server.py` 时会自动调用 `scripts/build_dict.py` 从 `data/raw/` 编译生成词库数据库（耗时仅数秒），完成后自动打开浏览器访问 `http://127.0.0.1:8765`。

可选启动参数：

```bash
# 指定监听地址与端口，且不自动打开浏览器
python server.py --host 127.0.0.1 --port 8765 --no-browser

# 仅手动重新编译词库数据库
python scripts/build_dict.py
```

### 运行单元测试

如尚未生成 `data/ime_dict.db`，请先运行一次词库编译脚本再执行测试：

```bash
python scripts/build_dict.py
python -m unittest discover -s tests -v
```

测试覆盖：拼音切分、全拼与 Viterbi 整句解码、简拼与前缀补全、上下文幽灵补全、自动新造词与 Bigram 联想学习、重启后 SQLite 持久化验证。

## HTTP API 一览

后端提供简洁的 JSON API，便于前端调用或二次集成：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/stats` | 获取词库统计与用户记忆统计 |
| `POST` | `/api/query` | 查询拼音候选词、切分路径与幽灵补全 |
| `POST` | `/api/predict` | 基于上文中文文本预测后续联想与幽灵补全 |
| `POST` | `/api/commit` | 提交上屏词条，触发词频/新词/Bigram 学习并返回后续联想 |
| `GET` | `/api/memory` | 获取已学习词汇、上下文联想对及统计信息 |
| `POST` | `/api/memory/word` | 手动写入自定义记忆词条 |
| `DELETE` | `/api/memory/word` | 删除指定记忆词条 |
| `DELETE` | `/api/memory/bigram` | 删除指定上下文联想对 |
| `GET` | `/api/memory/export` | 导出用户记忆库 JSON 文件 |
| `POST` | `/api/memory/clear` | 清空全部用户记忆 |
